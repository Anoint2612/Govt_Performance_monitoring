# HQ System (HQ Admin MVP)

## Protoype Demo (Early stage) -> https://youtu.be/lNuFMxR63es

## Backend
- Node.js + Express + Mongoose
- Base URL: `/api/v1`

Run backend:
```
cd backend
npm install
npm run dev
```

## Frontend
- React + Vite

Run frontend:
```
cd frontend
npm install
npm run dev
```

Ensure backend `.env` is configured with `MONGO_URI` and `JWT_SECRET`.
